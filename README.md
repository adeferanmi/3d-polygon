# 3D Polygon

OpenGL graphics programming project built with C++ and Visual Studio.

## Requirements

- Windows
- Microsoft Visual Studio 2022
- OpenGL compatible GPU

## Dependencies

This project uses:

- GLFW
- GLAD

## Building the Project

1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/3d-polygon.git

```

## Running

Open 3d-polygon.slnx
